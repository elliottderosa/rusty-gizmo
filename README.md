## Building
To clone the project from github, use:  
```shell
git clone https://github.com/ELLDER054/rusty-gizmo.git
```
Then, go to the directory and use cargo to build it.  
```shell
cd rusty-gizmo
cargo install --path .
```
Now you can use the `gizmoc` command to run gizmo files.  
```
gizmoc file.gizmo
```
